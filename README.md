# Medical Image Classification Using Deep Learning

A deep learning project for gastrointestinal image classification using the **CRCCD V1** dataset. This project compares multiple Convolutional Neural Network (CNN) architectures and ensemble learning techniques to identify the most effective model for medical image classification.

---

## Overview

The objective of this project is to evaluate the performance of different deep learning architectures on gastrointestinal image classification.

A total of **10 deep learning models** were trained and compared using standardized evaluation metrics to determine the best-performing approach.

---

## Features

- Trained and evaluated 10 deep learning models
- Compared multiple CNN architectures
- Implemented ensemble learning techniques
- Hyperparameter optimization
- Performance comparison using multiple evaluation metrics
- Medical image classification on the CRCCD V1 dataset
